# UrbanKart Sales Data Analysis

A Python-based data analysis project that focuses on cleaning, preprocessing, and analyzing a retail sales dataset using Jupyter Notebook. This project demonstrates the complete workflow of transforming raw data into meaningful business insights using Python, NumPy, and Pandas.

---

## Project Overview

The goal of this project is to clean a messy retail sales dataset and perform exploratory data analysis (EDA) to answer business-related questions and generate useful insights.

The project follows a real-world data analysis workflow:

- Data Cleaning
- Data Preprocessing
- Exploratory Data Analysis (EDA)
- Business Insights

---

## Dataset

The project uses the **UrbanKart Sales Dataset** containing information such as:

- Order ID
- Order Date
- Region
- Product Category
- Sales Channel
- Revenue
- Discounts
- Customer Details

The repository includes:

- **urbankart_sales_messy.csv** – Original dataset
- **urbankart_sales_clean.csv** – Cleaned dataset after preprocessing

## Data Cleaning

The following preprocessing steps were performed:

- Removed duplicate records
- Handled missing values
- Standardized inconsistent data
- Converted columns to appropriate data types
- Cleaned text values
- Formatted date columns
- Created a clean dataset for further analysis

---

## Exploratory Data Analysis (EDA)

The cleaned dataset was analyzed to answer several business questions, including:

- Which region generated the highest revenue?
- How did revenue change across different months?
- Which sales channel performed the best?
- What percentage of total revenue came from each channel?
- Which categories contributed the most to sales?
- What business recommendations can be made from the data?

---

## Key Insights

Through this analysis, the project identifies:

- Top-performing regions
- Monthly revenue trends
- Sales channel performance
- Category-wise business performance
- Actionable insights based on sales data
